## [1.0.0] - 2025-04-16
### Added
1. **Command Pattern**
2. **Memento Pattern**

### Notes
- This project provides reusable and extensible implementations of key design patterns for Unity.
- Current focus is on state management and command execution, with potential for future expansion to include other patterns like Singleton, Observer, or Factory.
